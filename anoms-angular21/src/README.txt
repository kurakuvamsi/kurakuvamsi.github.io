ANOMS Angular 21 - SRC ONLY

This folder is intended to replace the existing project's src folder.

IMPORTANT:
1. Routing requires @angular/router matching your Angular major version.
   For Angular 21:
       npm install @angular/router@21

2. Bootstrap 5.3.3 is loaded from jsDelivr in src/index.html.
   Internet access is required for Bootstrap CDN CSS/JS.

3. All feature images are local SVG assets under:
   src/assets/feature/

4. Do not delete src/assets/feature or the feature pages will show broken images.
